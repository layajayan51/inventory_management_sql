# inventory_management_sql
# 📦 Inventory Management - Low Stock Alert

## Overview
This project helps inventory managers quickly identify **products running low on stock** that need to be reordered.  
The database and queries are built in **MySQL** to track stock levels and reorder requirements.

## Tech Stack
- **MySQL** (database creation and queries)

## Features
- Database schema for inventory management  
- Query to flag products where `current_stock < reorder_level`  
- Simple, efficient way to monitor stock levels  

## Purpose
A practical project to demonstrate **SQL-based inventory analysis**, ensuring timely reordering and smooth operations.
